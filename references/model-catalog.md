# Model Catalog

Use this file after `routing-matrix.md` identifies the right neighborhood. Read only the sections that match the current problem.

## 1. Understanding Reality

| Model | Use when | Ask | Pairs well with |
| --- | --- | --- | --- |
| first principles | assumptions were inherited from analogy, habit, or convention | what must be true even if the current framing is wrong? | falsifiability, inversion |
| deduction / induction / abduction | the reasoning mode itself is unclear | are we deriving, generalizing, or inferring the best explanation? | information theory, Occam's razor |
| falsifiability | people keep collecting support and ignoring disconfirmation | what evidence would prove this view wrong? | first principles, map is not the territory |
| paradigm shift | current facts fit badly because the frame itself is stale | what changes if we swap the governing worldview? | dialectics, latticework of mental models |

## 2. Systems And Complexity

| Model | Use when | Ask | Pairs well with |

## 3. Decisions And Judgment

| Model | Use when | Ask | Pairs well with |
| --- | --- | --- | --- |
| expected value and probabilistic thinking | outcomes are uncertain but estimable | what is the weighted value across plausible outcomes? | ergodicity, opportunity cost |
