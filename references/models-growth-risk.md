# Growth And Risk Models

Open this file for growth, scale, tail risk, fragility, and survivability.

| Model | Use when | Ask | Pairs well with |
| --- | --- | --- | --- |
| compounding / exponential growth | small gains or losses stack over time | what changes if this process keeps feeding on its own base? | network effects, scaling laws |
| scaling laws | size changes the shape of the problem | what stops scaling linearly when this gets 10x larger? | compounding, diminishing returns |
| diminishing returns | more input keeps helping less | where is the marginal gain flattening out? | marginal thinking, opportunity cost |
| black swan and fat tails | rare events dominate outcomes | what extreme outcomes matter even if they are infrequent? | inversion, ergodicity |
| antifragility | volatility may help some systems and destroy others | how can we gain from stress while capping downside? | natural selection, barbell-like planning |
| ergodicity | average return hides individual ruin risk | can the actor survive long enough to realize the average outcome? | expected value, black swan |
