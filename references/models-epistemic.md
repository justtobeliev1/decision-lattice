# Epistemic Models

Open this file for truth-seeking, diagnosis, evidence quality, and frame cleanup.

| Model | Use when | Ask | Pairs well with |
| --- | --- | --- | --- |
| first principles | assumptions were inherited from analogy, habit, or convention | what must be true even if the current framing is wrong? | falsifiability, inversion |
| deduction / induction / abduction | the reasoning mode itself is unclear | are we deriving, generalizing, or inferring the best explanation? | information theory, Occam's razor |
| falsifiability | people keep collecting support and ignoring disconfirmation | what evidence would prove this view wrong? | first principles, map is not the territory |
| information theory | uncertainty reduction matters more than narrative elegance | what data would most reduce uncertainty per unit cost? | falsifiability, abduction |
| map is not the territory | dashboards, abstractions, or labels are being mistaken for reality | where is the model compressing away decisive detail? | first principles, paradigm shift |
| Occam's razor | explanations are proliferating without stronger predictive power | which explanation fits the evidence with the fewest moving parts? | abduction, falsifiability |
